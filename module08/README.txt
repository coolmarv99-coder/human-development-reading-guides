The guide uses native keyboard-accessible controls, visible focus, meaningful alt text, supportive retry feedback, no drag-and-drop, and no timer. Ordinary multiple-choice groups shuffle independently on every page load. Dropdown choices share one shuffled order within an activity while retaining “Choose…” first. Correctness uses stable internal values rather than displayed positions. Responses remain on the page and are not submitted to Canvas.
