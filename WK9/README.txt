# Human Development Module 9 Interactive Reading Guide

This GitHub-ready folder contains a Pattern A: Recognize and Connect reading guide aligned with OpenStax Chapter 10.

## Contents

- `index.html` — complete interactive guide
- `images/maya-module09.jpg` — optimized Maya story image
- `images/concept-module09.jpg` — optimized concept-supporting image

## Publish or test

Keep this folder structure unchanged. Extract the ZIP before testing, then open `index.html` locally. For GitHub Pages, upload the complete `module09` folder.

All image paths and filenames are lowercase and case-sensitive.

## Accessibility and privacy

The guide uses native keyboard-operable controls, visible focus, responsive layouts, meaningful alt text, live text feedback, retry opportunities, reduced-motion support, randomized multiple-choice and matching options, and a labeled progress indicator. No drag-and-drop or timed interaction is required.

Student responses remain in the browser. They are not saved, graded, interpreted, or submitted to Canvas.
