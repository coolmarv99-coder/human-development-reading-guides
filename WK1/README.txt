## Publish

Upload the entire `module01` folder without changing the folder structure. The image paths are case-sensitive. Open `index.html` to test locally or through GitHub Pages.

## Accessibility

The guide uses semantic landmarks, keyboard-operable controls, visible focus indicators, text feedback announced through live regions, responsive layouts, alt text, reduced-motion support, and a text-labeled progress indicator.

Student responses remain in the browser and are not submitted or saved.
